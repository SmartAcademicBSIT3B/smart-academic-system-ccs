PROBLEM: Can't connect to database
ERROR: getaddrinfo ENOTFOUND mysql-eac28ff...

SOLUTIONS:
✓ Check .env file exists in project root
✓ Verify DB_HOST, DB_PORT are correct
✓ Check DB_USER and DB_PASSWORD
✓ Ensure network can reach database
✓ Try from different network if behind VPN

PROBLEM: Still seeing errors after cleaning
SOLUTIONS:
✓ Run diagnose_requirements.js again
✓ Run test_fetch_requirements.js
✓ Check application console for errors
✓ Restart backend with: npm start

PROBLEM: Want to undo the cleaning
SOLUTION:
✓ Create backup before cleaning:
  CREATE TABLE ojt_requirement_submissions_backup AS 
  SELECT * FROM ojt_requirement_submissions;

✓ If needed, restore with:
  DROP TABLE ojt_requirement_submissions;
  RENAME TABLE ojt_requirement_submissions_backup 
    TO ojt_requirement_submissions;
